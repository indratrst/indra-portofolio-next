# Agent Instructions for Portfolio Redesign

## Project goal
Redesign the portfolio landing page starting from the hero section, with a premium dark aesthetic inspired by the reference at https://re-birth.framer.website/.

## Core design direction
- Prioritize a cinematic, editorial, premium feel
- Keep the palette dark with restrained neon accents
- Make the hero visually strong before any detail-heavy content appears
- Emphasize clarity, polish, and modernity over crowded layouts

## Rules for implementation
1. Start from the hero section before other sections.
2. Preserve a clean dark theme with soft gradients and subtle glass panels.
3. Use oversized typography with tight spacing for the main headline.
4. Keep CTAs minimal but impactful; avoid clutter.
5. Add soft, tasteful motion rather than heavy animation.
6. Maintain readability and responsiveness across mobile, tablet, and desktop.
7. Prefer strong visual hierarchy and whitespace over excessive decoration.

## Preferred stack usage
- Use Next.js + React for structure
- Use Tailwind CSS for styling
- Use lucide-react for small icons if needed
- Keep code simple and reusable

## Design checklist
Before considering the redesign complete, verify:
- Hero feels premium and modern
- There is a clear headline, supporting text, and CTA
- Right-side profile card or visual block feels intentional and balanced
- Background treatment adds atmosphere without hurting readability
- Layout remains clean on smaller screens

## Content style
Keep the text professional, confident, and concise. The tone should feel personal but not overly casual.

## Important constraints
- Do not copy the reference directly
- Do not overuse gradients or neon until the design feels noisy
- Do not add cluttered cards or too many tags in the hero
- Do not sacrifice accessibility for visual style

## Expected delivery
The implementation should produce a refined hero section that introduces the portfolio as a premium digital experience and sets the tone for the rest of the page.
